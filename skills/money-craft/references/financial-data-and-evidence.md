# 财务数据与证据

## 来源优先级

1. 上交所、深交所、北交所正式披露及上市公司正式报告。
2. 公司 IR 中与交易所披露一致的正式文件。
3. Fuyao 结构化数据，用于检索、时间序列和交叉核对。
4. 其他可追溯公开来源，只作补充背景。

财务报表与公司行动以正式披露为最终口径。行情和估值快照保留 Provider、request ID、抓取时间和数据时间，不把它们伪装成财报事实。

## 口径与差异

比较前必须统一证券、报告期、合并范围、币种、单位和累计/单季口径。差异率：

```text
abs(source_a - source_b) / max(abs(source_a), epsilon)
```

- `<= 1%`：可视为一致或舍入差异，仍记录两个来源。
- `> 1%` 且 `<= 5%`：显式展示差异和可能原因，正式披露优先。
- `> 5%`：阻断依赖该数字的估值和结论，回到原始报告核实。

常见原因包括单位、累计与单季、合并范围、披露更新时间、复权、股本变化和非 GAAP 口径。`null` 表示未披露，不得补零。

## 时间与复权

- 研究记录 `as_of`、报告期、披露日、行情数据时间和抓取时间。
- 当前快照使用实际成交价；历史比较默认使用前复权；总回报研究必须明确分红和复权口径。
- 同一张表或公式不得混用复权与不复权序列。

## 证据捕获

Provider 命令使用 `--capture-dir` 和 `--source-id S01` 保存脱敏请求、原始响应和 SHA-256 manifest。公开仓库中的 capture 目录必须位于已忽略的 `local/evidence/<case-id>/`；正式公告或网页证据也保存在该私有目录，并记录 URL、抓取时间、本地相对路径和内容哈希。

报告正文用 `[S01]` 引用。公开报告的来源索引必须能解析到正式 URL 或公开 `evidence-manifest.json` 条目；manifest 只发布来源元数据和 SHA-256，不发布 Provider payload、下载的公告或网页快照。计算使用 Decimal，并在报告中嵌入：

```html
<!-- money-craft-calc: {"id":"C01","operation":"multiply","inputs":["10.5","20"],"expected":"210","tolerance":"0.000001"} -->
```

支持 `add`、`subtract`、`multiply`、`divide`、`cagr` 和 `weighted_average`。审计失败时先修事实或公式，不删除回归门禁。
